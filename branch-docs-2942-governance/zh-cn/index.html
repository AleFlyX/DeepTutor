文档 EduHub 生态 GitHub — Stars

八个入口，串起你的学习。

对话、日历、笔记本、学习、资料跟随当前工作区；伙伴与个性化属于账户。切换科目时复用熟悉的助手，同时让各项目的材料保持清晰。

I

工作区

按科目或项目分开组织，让各自的对话、学习与资料留在对应工作区。

 II

对话

结合上下文提问、选择模式，由同一个智能体循环调用工具、技能与资料。

 III

日历

把账号日程与工作区任务、到期复习、定时指令和学习活动放在一起规划。

 IV

笔记本

把来源整理成自己的页面，与 Dito 讨论段落，并从收藏夹插入证据。

 V

学习

通过书籍、精通之路、阅读与练习开展学习，对话始终围绕当前活动。

 VI

资料

复用当前工作区的聊天记录、收藏、题目、学习日志与知识库。

 VII

伙伴

账户级的持久伙伴，拥有明确的工作上下文、可复用指令与 IM 渠道。

 VIII

个性化

将角色、技能、外部智能体和已连接工具带到不同工作区使用。

几分钟就能跑起来。

四种安装方式 —— 挑一个适合你的。最终都落到同一个配置好的工作区。

已发布的完整 Web 应用 + CLI 包（1.7+ 模块化安装）。需要最新 dev 请选源码。

# 1. 准备运行数据目录
mkdir -p my-deeptutor && cd my-deeptutor

# 2. 安装、配置、启动
pip install -U "deeptutor[full]"
deeptutor init
deeptutor start
然后打开 127.0.0.1:3782 完整指南

已发布的稳定版镜像。需要当前 dev 时，请使用源码构建 Dockerfile。

docker run --rm --name deeptutor \
  -p 127.0.0.1:3782:3782 \
  -v deeptutor-data:/app/data \
  ghcr.io/hkuds/deeptutor:latest
打开 127.0.0.1:3782 即可，应用会在内部代理 API。数据持久化在命名 volume 里。 完整指南

使用当前 dev 源码，安装完整 Python 依赖与前端。

git clone --branch dev https://github.com/HKUDS/DeepTutor.git
cd DeepTutor

python3 -m venv .venv && source .venv/bin/activate
python -m pip install -r requirements/full.txt
python -m pip install -e . --no-deps
( cd web && npm ci --legacy-peer-deps )

deeptutor init && deeptutor start
Python 3.11–3.14 · Node.js 22 LTS。start 加 --dev 可启用前端热重载。 完整指南

从终端使用当前 dev 源码；若要最小 core 环境，请按指南选择独立 wheel 安装。

git clone --branch dev https://github.com/HKUDS/DeepTutor.git
cd DeepTutor

python3 -m venv .venv-cli && source .venv-cli/bin/activate
python -m pip install -r requirements/full.txt
python -m pip install -e . --no-deps

deeptutor init --cli
deeptutor chat
跳过前端安装。使用知识库时配置 embedding；运行可选能力前检查模块状态。 完整指南
