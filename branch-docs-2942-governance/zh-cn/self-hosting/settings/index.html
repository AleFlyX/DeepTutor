设置

设置（Settings）是 DeepTutor 的运维控制面板。大多数版块采用草稿—应用（draft-and-apply）模式：你先编辑草稿、测试，再 Apply（应用）——这样一次糟糕的提供商改动永远不会搞垮一套正常的配置。配置值持久化到你账户下的 data/user/settings/*.json（以及少数几个 YAML 文件）。文件名和 setup 能力可写的键见配置文件。

它在哪里

Section titled “它在哪里”

点击左侧栏底部的 Settings（设置）。可搜索的导航器打开独立页面，按个人、学习与对话、模型与服务、功能与集成、系统和已归档分组。常规页放置界面语言和模型输出语言两个开关；运行状态页显示后端健康、进程内存及运行就绪矩阵，把各能力评为阻塞、警告或建议，未配置的可选能力不算故障。用量统计查看模型用量与对话活动；已归档的聊天可以搜索、恢复或删除归档会话。侧栏功能入口与聊天记录的顺序仍是单机偏好：拖动即可排序，也可把功能入口收进 More。

版块控制什么
Appearance（外观）主题、学习文字与代码块外观。
Network（网络）前端代理访问后端的 API base、端口与 CORS。
Workspace（工作区）系统、通用与自建工作区、根目录和存储迁移。
Models（模型）提供方、语言模型、后台任务模型、嵌入模型、搜索、语音与多模态生成。
Knowledge Base（知识库）文档解析引擎。
Chat（聊天）视频学习、工具、各能力参数、起始建议与附件上限。
Partners & Agents（伙伴与智能体）可从聊天调用的十种本地 agent harness。
Memory（记忆）整理器的分块、预算、去重与引用策略。
About（关于）当前版本、安装类型、发布通道、更新检查与安全更新路径。

先判断配置范围

Section titled “先判断配置范围”

设置负责应用、服务与工作区策略；个性化负责可复用的人格、技能、智能体与服务连接；当前工作区的主页、学习、资源负责对话、学习与材料。伙伴拥有独立的账号级入口。

个人偏好随账号跨工作区保留。提供商基础设施、本机 agent 执行、应用安装等部署配置可能需要管理员。修改工作区资源选择，不会改变资源所有权或部署权限。

工作区资源与指令

Section titled “工作区资源与指令”

打开设置 → 工作区创建或管理工作区，填写易识别的名字，按需配置根目录，并为项目或课程补充指令。工作区指令随该工作区的工作应用；可复用人格仍是单独的账号预设。

对已有工作区打开 Assigned resources（分配资源）。技能、MCP 服务、知识库可以分别选择：

模式效果
Inherit available resources（继承可用资源）保留账号原有访问规则，新变得可用的资源会自动纳入
Only selected resources（仅所选资源）只允许勾选项；一个都不勾选就不允许该类资源

保存后回到主页检查资源选择器。分配建立的是引用，移除分配不会删除库里的原始资源。Manage library进入相应资源库，修改资源本身。若条目标记为不可用，应修复连接、安装或来源；保留失效引用不会自动恢复资源。

工作区策略是范围上限。对话中选择技能或 MCP 服务可以继续缩小范围；清空对话选择后恢复继承工作区。共享部署还会应用用户授权，不会因为工作区选择而显示别人的文件或凭据。

Partner 可以绑定所有者的工作区，共用最新材料。在工作区资源入口维护材料，在伙伴入口配置身份、渠道和模型，详见伙伴。

外观

Section titled “外观”

包括主题、学习文字与代码块。两个语言开关已移到常规设置页：界面语言只覆盖导航、设置与状态文案，模型输出语言决定聊天与能力回复的语言。内置五款主题：System（跟随系统）、Default（纯白干净、蓝色点缀）、Cream（暖调、纸感、赤陶点缀）、Dark（在近黑底上保留 Cream 的暖意）、Glass（深色渐变上的半透明紫色面板）。每个磁贴都会预览它所应用的主题。另有 Code blocks 面板设置语法主题、行号与换行。

模型

Section titled “模型”

这里集中管理所有模型与服务：语言模型、用于自动调用以及 Math Animator/Video Lesson 修复的 task model、embedding、网络搜索、语音（TTS/STT）以及图像/视频生成。每项服务由 profile 与模型目录组成，修改凭据后会自动发现模型，支持批量导入；LLM 和 Task profile 可选择提供方支持的 API format；默认 URL 随格式切换，自填地址保持不变。每个模型可沿用自动能力判断，也可覆盖工具调用、图像输入、JSON 输出与推理支持。提供方页保存同一厂商的一份凭据，并把它连接到该厂商提供的所有服务——密钥只需输入一次。语音模型驱动朗读与输入框麦克风，图像/视频模型会成为聊天工具。请在 Apply 前先 Test；测试通过只证明 profile 能完成最小调用，并不保证该模型适合所有 capability。

在上下文中查看 Models 页面见聊天工作台 → 配置聊天能用到的东西，配置范例见模型与搜索提供商。

知识库

Section titled “知识库”

把上传内容转成文本（供知识库与出题用）的文档解析引擎——Text-only、MinerU、Docling、Tika、markitdown、PyMuPDF4LLM 或 LiteParse。本地模型下载默认关闭。详见知识中心 → 文档解析。

聊天

Section titled “聊天”

五项相关控制分别设有独立页面：

  • Video Learning（视频学习）——选择字幕提供方，配置自托管 Invidious 的浏览器/API origin，并测试连接。Reading 使用原生 YouTube 播放；修改这些设置不会重建材料或清空观看进度。
  • Tools（工具）——聊天智能体可调用的内置工具。体验增强类工具（brainstorm、web_search、paper_search、zotero_search、reason、geogebra_analysis，以及配置好相应模型后可用的 imagegen / videogen）由你开关；其余的——包括检索和工作区执行工具——按上下文或能力归属挂载，只有当前轮次允许时才可用。
  • Capabilities（能力）——为 Chat、Solve、Question、Research、Math animator、Visualize 与 Co-writer 设置各能力的 LLM 参数与运行时旋钮（温度、token 预算、循环上限）。
  • Starting points（起始建议）——多少条近期活动参与生成空输入框下面那三行建议。
  • Attachments（附件）——聊天附件的大小上限与提取预算（管理员门控）。

MCP 服务不再在这里：每个账号都从个性化的 MCP 服务商店（/space/mcp）自行安装，或按 URL 添加远程服务器。见 MCP 扩展。

在聊天里配置它

Section titled “在聊天里配置它”

这一页上的大部分东西，也可以直接开口。「把界面切成中文，再换一个更好的 PDF 解析器」就是一句话，助手会检查这套安装、应用改动，并告诉你代价是什么——立即生效、需要重启，还是需要重建索引。

这只是一个多挂了四个工具的普通对话回合，所以在别的事情做到一半时问一句配置，不会把你的知识库和搜索工具一并丢掉。它依据客观信号激活——你选了这个能力、你的消息把一个动作词和一个配置对象凑在了一起，或者这是你在一套仍有明显缺口的安装上的第一次对话——而不是依据模型觉得配置这件事是否相关。

有三条规则让它不至于莽撞：

  • 新模型或新提供商在提交前先被探测。 探测跑在一份从未落盘的候选配置上。没有这个顺序，就会变成先写后验——而下一个回合，包括那个本该用来撤销错误的回合，会跑在一个根本连不上的模型上。
  • API key 永远不进模型上下文。 需要凭据时，助手会在输入框里打开对应的表单，由你的浏览器把 key 直接提交给服务端。可写设置表里的任何一项，甚至无法表示一个密钥。
  • 每个旋钮都自带作用域与影响。 个人设置存在你自己的档案里，部署级的仅限管理员。这是数据而非提示词礼仪，所以「要不要重启」这个回答是可靠的。

慢活它也能干：安装一个解析引擎、下载它的模型权重，并在同一次调用里跟完安装日志，而不是把轮询丢给你。只接受白名单里的引擎 id——绝不接受任意包名或命令。

伙伴与智能体

Section titled “伙伴与智能体”

配置你能在聊天里调用的本地 agent harness——Claude Code、Codex、Grok CLI、Antigravity CLI、Kimi CLI、opencode、MiMo Code、Hermes Agent、OpenClaw 与 DeepSeek Harness，也支持远程 Hermes 连接。各本地配置块会显示本机是否找到命令，支持时可同步模型列表，并暴露各 harness 的无人值守运行参数。详见我的智能体。

记忆

Section titled “记忆”

调校基于分块的整理器：Update 与 Audit 各自针对每个 L2 界面与 L3 槽位的 LLM 轮数预算，以及 Dedup 迭代次数。详见记忆 → 调校整理器。

关于与更新

Section titled “关于与更新”

侧栏版本徽标会进入 About，并用状态点提示更新情况。About 会识别当前版本、安装类型、稳定发布通道、最新正式版与发布说明。检查结果缓存 24 小时，也可为离线或受控部署关闭；未经确认，DeepTutor 绝不会开始安装。

自动 Update and restart 只在激活虚拟环境里的常规 PyPI 安装、且 DeepTutor 管理 launcher 进程时提供。进行中的对话必须先结束，更新器才能启动；随后它会交接给 worker，升级软件包，再用同一数据目录重连。源码工作区继续走 Git，Docker 更新镜像，未知或直接 artifact 安装则只显示手动路径。

部署注意

Section titled “部署注意”
  • 项目根目录的 .env 被刻意忽略，不作为应用配置。
  • 除非你设置了 DEEPTUTOR_HOME 或用 deeptutor start --home，运行时设置都在 data/user/settings/ 下。
  • Docker 浏览器访问前端 origin，由前端代理连接后端。分离部署时，在 Network 设置代理访问的后端地址。
